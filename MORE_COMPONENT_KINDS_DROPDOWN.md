# Insert — More Kinds dropdown

- The Insert ribbon keeps six frequent component groups: Passive, Semiconductors, Logic ICs, Microcontrollers, Sensors, and Output Devices.
- **More kinds** now opens a scrollable dropdown containing only the remaining catalog kinds, with live counts; it no longer opens All Parts.
- Selecting an item opens that specific kind in the compact, searchable Insert gallery. Existing card drag-to-place and search remain unchanged.
- Dropdown closes on selection, clicking outside, Escape, or resize; menu is outside the ribbon overflow container so it remains visible.
- All Parts is unchanged and still provides the complete browse/search/favorites flow.

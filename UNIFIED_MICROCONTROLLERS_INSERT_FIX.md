# ElectroLab Insert ribbon — unified Microcontrollers

- Removed the redundant **Controllers** category.
- **Insert → Microcontrollers** now displays Arduino Uno, Arduino Nano, Arduino Mega 2560, ESP32 DevKit, and Raspberry Pi Pico together.
- **All parts** and the standalone Component Library use the same category.
- The category buttons use distinct icons to avoid confusing every kind with a CPU.
- Part IDs, per-pin terminal IDs, off-breadboard physical positions, wire connectivity, saved circuits, and the ribbon behavior are unchanged.
- This patch fixes category organization. It does **not** add Arduino/ESP32/Pico firmware emulation or fully physically accurate 3D CAD models.
